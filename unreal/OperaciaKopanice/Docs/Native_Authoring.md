# Native Authoring

The project targets Unreal Engine 5.8.2. Run `Content/Python/bootstrap_native.py` once from the Unreal Python console to create starter materials, landscape layer assets, Blueprint subclasses, PCG graphs, a footprint render target, and the viaduct actor.

Use Blender for custom high-poly organic sculpts, clothing topology, weapons, vehicle chassis, UVs, and baking. Export clean FBX at centimeter scale. Use Unreal Modeling Mode for modular kit assembly, bevels, collision proxies, Nanite conversion, landscape materials, PCG placement, RVT footprints, weather, AI perception, and nav state.
